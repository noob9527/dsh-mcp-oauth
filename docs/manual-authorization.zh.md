# 手动粘贴授权响应

[English](manual-authorization.md)

此功能包含在尚未发布的 0.2.0-rc.1 开发版中，npm 0.1.0 不支持。适用于个人 DSH 实例无法接收自动回调的场景。本机和远程自动回调方式保持可用，不支持多人共享 Host。

## 选择回调地址

手动模式不启动监听端口，也不需要回调反向代理。它仍使用 Authorization Code + PKCE S256、配置中的回调地址和一次性 state，只是通过手动提交传递授权响应，不是新的 OAuth 授权类型，也不是 token 导入功能。

在 CIMD 文档或预注册客户端中登记以下任一种精确回调地址：

- 可信的 HTTPS 授权响应展示页，例如 `https://callback.example.com/oauth/response`。页面运营者必须禁止记录查询参数、加载第三方脚本或统计组件，以及持久化响应。页面可以展示或复制完整回调 URL，但不能代替插件换取 token。本插件不负责部署此页面。
- 带明确端口和路径的 HTTP 本机回调地址，例如 `http://127.0.0.1:6274/oauth/callback`。由于自己的电脑没有运行接收器，授权后浏览器可能显示连接失败，此时仍可复制完整地址栏。应选择未被其他本机应用占用的端口，否则其他应用会收到授权响应。

授权服务器必须允许所选回调地址。浏览器显示同意授权成功，并不代表插件登录已经完成。远程 DSH 必须通过经过认证的 HTTPS 访问，每位用户拥有独立 Host 进程、profile 和凭据存储。

## 登录步骤

1. 进入 Plugins → Built-in plugin settings → OAuth MCP，添加或编辑服务。
2. 在“回调方式”中选择“手动粘贴授权响应”。填写 MCP 服务地址、注册方式、客户端元数据 URL 或预注册身份、权限范围和已登记的回调 URL。此模式不使用内部监听端口。
3. 保存后点击“登录”，打开授权页面，只批准自己刚发起的登录。
4. 复制最终的完整回调 URL，包括 `code`、`state` 和存在时的 `iss` 参数。不要复制初始授权链接、成功提示文字、access token 或单独的授权码。
5. 回到 DSH 中同一服务的待完成登录，将内容粘贴到“完整授权回调 URL”输入框，点击“提交授权响应”。不要将其粘贴到聊天或发送给他人。
6. 提交后输入框会清空。“已收到响应”仅表示接收成功；请继续等待 DSH 显示“已授权”和“已连接”，并发现工具。

输入框以掩码显示，不写入浏览器本地存储，仅属于当前待完成登录。取消、完成、过期或离开设置页会移除该输入。后端使用内存中的 verifier 换票，再通过已有凭据存储保存授权记录。提交被拒绝时也会清空输入框；如果该次登录仍在等待，可重新粘贴正确响应。

## 校验与恢复

插件只解析提交的 URL，不会请求该地址。它会校验配置中的精确 origin 和路径、URL 不含用户信息或片段、一次性 state 匹配、响应参数不重复，以及提供 `iss` 时它与已发现 issuer 一致。响应必须包含非空的授权码或 OAuth 错误，两者不能同时存在。重复参数、token 参数、其他未支持参数，以及超过 16,384 个字符的响应会被拒绝。标准 `error_description` 和 `error_uri` 字段可以接收，但不会回显，也不会访问其中的链接。

格式错误或不匹配的响应不会消耗当前登录机会。有效授权码或拒绝授权响应只能被接收一次，重复提交会失败。取消、超时、停用或删除服务、清除授权以及卸载插件都会使待提交响应失效。进程重启会丢失待完成登录的 state 和 verifier，此时需要重新登录。旧登录或其他服务的响应不能完成新登录。

如果授权码已过期或已使用导致换票失败，应重新发起登录，不要反复提交同一个响应。已有刷新和连接行为不变。手动输入仅用于交互式授权，成功刷新 token 不需要再次粘贴。

## 敏感信息处理

提交经过插件仅允许所有者访问的直接 Remote API，不经过聊天、模型工具或会话命令。API 不返回提交的 URL 或授权码，错误使用固定错误码。自动化测试验证非 owner 请求被拒绝，提交的授权码不出现在返回状态、服务配置、授权记录或捕获的日志中。已检查的官方一元 Remote 调用路径不记录请求参数，但这不能替代对额外部署诊断功能的检查。

不要让网关诊断、自定义追踪或调试中间件记录 `mcpOAuth/submitResponse` 请求体。剪贴板、浏览器历史和目标回调页面在清理前可能保留响应，插件不会清除这些位置。不要把授权链接或回调参数写入仓库文件、截图、Issue 或分析记录。此仓库仅使用保留域名和本地 fixture。
